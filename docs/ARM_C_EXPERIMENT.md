# Arm C: replay receipts and evasion-cost search (lab only)

Base: `c17141f`. Reproduce with `python -m pytest -q tests/test_arm_c.py tests/test_lab.py` and `PYTHONPATH=. python cviaf/lab/arm_c_measure.py` (numpy, pytest, scikit-learn). All local measurements are CPU, Python 3.10 / numpy 2.2.6.

## U4

The replay capsule binds the float32 image hash, enrolled model digest, inference config and hash, raw output and quantized hash, environment, and tolerance under a lab HMAC. The separate verifier checks *all* seals and field digests, samples *after the ledger is frozen* using an auditor-held secret, loads the independently enrolled model, hashes retrieved inputs, re-executes predictions and compares rows within declared tolerances. This does not replace production DSSE, independent build, secure key storage or chain/checkpoint verification. The signer is able to create plausible seals for wrong outputs; that is exactly the attack tested.

- 1,000 lab records, 50 wrong-model output records (5%), correctly HMAC-sealed and claiming the enrolled digest: ordinary digest checks pass by construction. Sampling k=59 for q=0.05 and miss probability=0.05 yields analytic escape bound `0.95^59 = 0.04849`. The test repeats 200 secret audit seeds, requires detection in at least 190 trials; actual count recorded in run output separately. Sampling is without replacement, making the binomial bound conservative when at least 50 out of 1,000 are forged. Under that exact 50/1,000 finite-population design, the hypergeometric miss probability is C(950,59)/C(1000,59), approximately 0.04415; the independent-draw 0.04849 remains a conservative approximation. For 10/200 with the same k=59, the without-replacement miss probability is C(190,59)/C(200,59)=0.02750, versus 0.95^59=0.04849. Do not conflate the two sample sizes.
- 500/500 clean `TinyDetector` receipts replayed with zero findings; audit ~0.59 s (roughly 50,600 records/minute). This is **not** YOLOv8n throughput or cross-hardware tolerance. Those acceptance tests remain open.
- Model and input enrollment, signed ledger freeze, unique record IDs and unpredictable audit key are required operational assumptions. The HMAC is a *lab seal*, not a non-repudiable signature. The service that can replace the trusted model/input registry also defeats this control.

## U5

`evasion.py` offers a bounded finite grid with successive-halving candidate allocation and a separate full-grid validation pass, fixed clean calibration threshold, deterministic seed, version digest and per-detector curve. Budget here is fraction of output-score traffic the adversary can dilute with ordinary scores or suppress. It **does not** implement the v4 model-axis variance-flattening or parameterized pixel attacks. Neither a finite-grid minimum nor an empirical 5% cut proves safety against unseen families. The current measured MVP OGA attack failed its ASR gate: null-adjusted ASR=0.150 (<0.50), so its score curves are diagnostics, not valid attacker-budget claims.

With 600 epochs, n_train=240, n_eval=80, and 60 evaluated clean/triggered images, the ungated baseline TPR at a conservative empirical 5% FPR cut was CTC 0.000, FTC 0.017, refdiv 0.167. All three are already below the target 0.5 at zero attack budget. Their B* is **undefined**, not zero-cost evasion. The search properly reports `attack_unqualified` and no B*; even if the attack passed the gate, these baseline TPRs would mean `already_below_target`. For refdiv, diagnostic dilution TPR at budgets 0, .3, .6, .9 was about .158, .141, .100, .066 (n=3,072 resamples per point; repeated same 60 images, not independent power trials). Search computation after training was ~3.3 s locally. The v4 acceptance goal (known evasion points recovered plus one cheaper evasion, measured B* on ASR-qualified models) is **not met** by this experiment. It would be misleading to claim otherwise.
