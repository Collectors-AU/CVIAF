# Model-asset decision audit

Base: `c17141f0f58f4a5f6f0afce8e0f5719c61fcdd46`. Companion measurements: `results/model_asset_measure.json`, grounded in the sibling's factorial `results/null_suite_day1_s5-s7.json`. The latter applies identical trigger recipes to clean and attacked weights on the same images. No asset threshold was selected on attacks.

## Diagnosis

`compare.model_axis` used each suspect model's own 80 bare-image scores as a calibration null, then compared them to stamped images. That measures the stamp even on clean weights. It formed image p-values with floor 1/81, multiplied the minimum across three signals by three, then Cauchy-combined 80 fused image p-values. At seed 5, legacy p was .0589 OGA, ~.118 ODA, .0445 RMA; the threshold fails OGA and ODA even on the confounded measure. The Cauchy statistic spreads a sparse anomalous tail across all images; the Bonferroni fusion makes its finite-sample floor .037. More fundamentally, *no aggregation of the bare-versus-stamped score establishes a model backdoor*: a clean model reacts to the stamp. The comparison's clean model fed the identical bare images to both sides, an invalid negative control. The local one-line `clean_peaks['ftc']` fix merely enables this diagnostic, not a valid null.

## Corrected rule and measured verdict

`model_asset_rule.py` defines a paired stamp response per independently trained model, then tests its absolute deviation from the clean-model median of that response against other independently trained clean models with the same prespecified stamp, evaluation distribution, signal configuration and trusted reference. Bonferroni over two signals (CTC and refdiv, not FTC) gives one conservative model-asset p-value. At alpha=.05, the conformal floor requires at least 44 independent clean models (5 prespecified center-fit models and 39 disjoint rank-calibration models). If fewer, it **abstains**, not clears or convicts. All 3 clean controls and all 9 attack assets in the seed 5-7 factorial diagnostic therefore abstain. OGA 0/3 convictions (one net-ASR-positive), ODA 0/3 (none with net ASR >=.5), RMA 0/3 (three net-ASR-positive). No FPR <=5% can be claimed: measured clean conviction count is 0/3 with abstention 3/3, not a calibrated operating point. At least 44 independent clean models and separate held-out clean seeds are needed before the nominal alpha claim can be tested; merely taking more images does not help the rank floor. Multiple tested model assets additionally need batch-level FDR/FWER control, rather than saying each marginal test guarantees a corpus-wide 5% error rate.

The sibling null suite shows conditional stamped-backdoored versus stamped-clean AUROC CTC .506/.107/.268 for OGA/ODA/RMA, refdiv about .51-.53; independent clean peers can differ as much. FTC conditional AUROC .474/.411/.407 and contributes no asset convictions. Raw ODA ASR was high even on clean weights, with net ASR .087/.037/.213. Only OGA seed 6 and all RMA seeds meet the diagnostic net-ASR .50 floor. These measurements show a detector-information blind spot, not merely an aggregation choice. A rule that convicts all OGA/ODA/RMA at 5% clean FPR on this material would exploit a stamp confound, label weak implants as positives, or claim unmeasured type-I control.

## Scope and next measurement

This is a synthetic three-seed diagnostic, not a deployment benchmark. Build a larger set of independently trained clean models under exactly matched image/stamp protocols and a separate held-out seed set, prespecify the probe recipe and reference, and find a new model-specific behavioral signal before expecting ODA/RMA power. Do not call old legacy image-Cauchy p-values asset convictions; `compare.py` now exposes them for diagnostics while abstaining operationally until an external clean-model null is supplied. Its existing baseline and data/provenance axes are unchanged. The null suite patch is a separate companion and should be applied independently; this lane's patch does not include it.
