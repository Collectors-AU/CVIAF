# Consolidated CVIAF v4 status

September 28, 2026. This integration is based on the public `c17141f` checkout, not a later DeepSeek push. The code is a tested integration of separate patches, not a completed external deployment benchmark. Synthetic 64 x 64 data and the checked-in MVP/Day 1 models are the available substrates. Newly merged behavior has not yet been remeasured across the complete distributed matrix. Read full JSON evidence and run provenance before publishing a statistic.

## What changed and why

- Benchmark work now has frozen per-seed/attack shards, a seed/spec registry and verified artifact merge. Corpus models can train in parallel; final compare/eval recomputes on the complete merged corpus. Per-shard JSON averages are invalid because controls and thresholds depend on the entire corpus.
- Model-integrity scoring no longer turns stamp-sensitive image statistics into a backdoor conviction. A paired, model-level rule is available but abstains unless supplied with at least 44 independent clean models; the present factorial diagnostic has too few. FTC is kept as a diagnostic rather than a validated detection claim. The new null suite measures bare/stamped on clean/backdoored weights; its conditional controls found no supported backdoor-specific image-level signal.
- Data-integrity lanes add a separate reference-trained label-flip signal, patch-local trigger signal, and opt-in global-chroma experiment. A declared-domain mismatch abstains. An optional asset-level label-consistency gate has synthetic matched-domain power but is not on by default. The review queue can group duplicate co-flags and prioritize analyst work; its local-FDR value is a ranking estimate, not a calibrated probability. The grouped-BY fusion experiment is isolated, not the production decision default.
- Drift now distinguishes natural, suspicious, under-determined and unavailable attribution using a calibration battery. The effect-size gate is opt-in and needs an independently calibrated floor for its batch size; no provisional 0.2 floor silently becomes a deployment standard. The MMD permutation test is seeded. The natural-drift calibration is generated separately and its digest is checked on load; the run-local assessment record has a different filename so it cannot overwrite the arbiter's calibration.
- Provenance uses explicit Ed25519 signing by default, separated public verification, algorithm-bound signatures and chain member signature checks. HMAC requires an explicit opt-in and does not provide a public-key origin claim. An optional signed report/audit checkpoint plus offline verifier detects deleted suffixes against a pinned latest count/root. An unanchored seal chain still cannot detect a deleted tail; the strict expected-failure test preserves that limitation. Pre-v3 seal archives need a documented migration or separately audited legacy verification path, not silent reinterpretation.
- V4 planning, plugin contracts, schema and live bridge are present, but the planner's estimated costs are not runtime enforcement, the included null battery is not operational calibration, and the legacy execution path has not been replaced end-to-end. Scale harness refuses ambiguous decoders and the old single-label `assess` route refuses multi-box data or missing images rather than fabricating success.

## Measurement truth and limits

The pre-integration `c17141f` clean assurance run was reported CRITICAL/quarantine with 17 findings, including OOD on 223/240 known-clean images and a clean-vs-clean MMD p=.01. That is a baseline failure, not proof the integrated package cures it. Arm H's lab clean battery reduced pooled proxy false-abstain 33.8% to 6.6%, but one desert/summer/clear cell worsened from 4.2% to 16.7% on one seed. Arm J's measured duplicate-flood review tasks were 59 rather than 99 for 48/48 catch; its ood_insert operator cost worsened by 1.18x. Arm B's residual-risk curves leave any unpowered cell unbounded and force review; the separate label-consistency trial observed 32/32 detections at 1/240 flips with 0/32 clean flags **only on the declared default synthetic scene**. Zero of 32 independent clean flags has a one-sided 95% upper FPR bound of about 8.94%, not <=5%. Fifty-nine independent clean assets with zero flags would give an upper bound <=5%. Use `scripts/clean_slice_report.py` on whole-corpus compare JSON for kind/domain slices and abstention counts; its exact bounds assume independent assets, so correlated seeds need stronger validation. The 0/3 clean model-asset convictions in the factorial check all abstained and say nothing about a calibrated FPR.

Arm C's receipt replay verifier caught 192/200 audit seeds at k=59 in its measured trial. The independent-draw escape approximation at 5% forgery is 0.95^59=4.849%; for exactly 10 forgeries in 200 records sampled without replacement, the exact miss chance is C(190,59)/C(200,59)=2.750%. The actual Arm C report used 50/1,000, where the exact finite-population miss chance is approximately 4.415%. State the sampling design before quoting either number. Its U5 evasion test was unqualified by the ASR gate, so B* remains undefined. Arm A's repeated-testing monitor avoided observed clean alarms but missed the delay criterion (50 looks vs fixed test's one). Arm D AUM had 85% label-flip FPR; Arm E's embedding spectral had 8.1% label-flip FPR, above the 5% bar. They remain optional research appendices, not production verdicts.

The older eight-model MVP comparison JSON is pre-integration evidence, not a result for the new pipeline. Old model CTC/FTC/refdiv signals are stamp-confounded; the matched-stamp null suite and asset-rule documents carry the corrected interpretation. No population FPR <=5%, real-image/backbone generalization, ONNX/TorchScript export parity, or end-to-end V4 operational enforcement is established by this patch. Offline verification assumes separately pinned trust material; offline key revocation is not established. Access tiers limit checks. Do not turn a 0/N count into a zero-risk claim.

## Reproduction gate

Install `.[full,dev]` into a venv, run `pytest -q`, freeze a plan at the final commit, train and transfer every expected shard, verify the merger and run compare/eval over the complete merged corpus. Recheck every declared scene and attack class separately, including false alarms, abstentions, confidence bounds and provenance assumptions. Keep source commit, package versions, manifest digest, artifact SHA-256, logs and full JSON. In this integration clone, 149 tests passed and one unanchored seal-chain truncation test was expected to fail before later edits; rerun on the final integrated base. The tested one-model compare smoke is not a full validation run.

## Opt-in synthetic label gate follow-up

Default `cviaf lab compare` remains label-flip blind at the asset verdict and BH item mask. The separate `label_flip_lane` box-loss diagnostic is reported but does not change the verdict. This is deliberate: no trusted clean annotation reference can be assumed from an arbitrary submission. The follow-up adds `cviaf lab label-gate-fit --corpus runs/mvp --out /safe/mvp-label-gate.json` and `cviaf lab compare --corpus runs/mvp --label-gate-protocol /safe/mvp-label-gate.json --json /safe/mvp-label-gated.json`. The first command freezes a synthetic generator reference fitted on scene seeds 10000-10003 and calibrated on 80 clean asset seeds 11000-11079, disjoint from the target models, with declared domain, asset digests, target IDs and checksum in JSON. The second refuses a target, domain or alpha mismatch. It is opt-in and synthetic-scene only; a local checksum detects accidental editing but is not an authenticated trust anchor. On the checked-in MVP seed-5 corpus, the gate flags the label-flip asset (24 mismatched images, p=1/81=.01235 at split alpha .025) while the single clean asset has zero mismatches and remains clear. This one asset pair does not validate population FPR, and the existing BH sample mask still has 0/24 label-flip hits. Do not present the gate's asset flag as 24 calibrated item detections. The earlier 32/32 at 1/240, 0/32 clean trial remains a separate matched-domain experiment with a one-sided clean FPR upper bound of about 8.94% under independence.
